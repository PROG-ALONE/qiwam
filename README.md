# قِوام

منصة تعليمية عربية بعلوم جسم لاعب كرة القدم: التشريح، والحركة، والتأهيل، وكرة القدم، والغذاء، وقصة حقيقية.

- الخطة الكاملة: [`PLAN.md`](PLAN.md)
- حالة المحتوى: [`CONTENT_STATUS.md`](CONTENT_STATUS.md)

## التشغيل محلياً

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## الاختبار

```bash
python3 tests/walk.py http://localhost:8000/ /tmp/shots   # يمشي على المدخل كامل بقياس آيباد وموبايل ولابتوب
```

المحتوى تعليمي، ولا يغني عن الطبيب أو المعالج الطبيعي.
